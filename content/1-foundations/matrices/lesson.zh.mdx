打开一个 Transformer 看看，几乎每个部件都是矩阵乘法。把这一种运算练到觉得轻松为止。
做到这一点，课程后面的内容会容易得多。

**矩阵**（matrix）就是一张数字表。它的**形状**（shape）说明这张表有多大：形状 (2, 3) 表示 2 行 3 列。
`C[0][1]` 表示矩阵 `C` 第 0 行、第 1 列的那个数。

## 1. 一次算一格

只有一条规则：**结果第 i 行、第 j 列的那一格 = 左边矩阵的第 i 行 · 右边矩阵的第 j 列。**
这里的“·”（**点积**，dot product）意思是：把两个列表逐个数相乘，再全部加起来。行和列都从 0 开始数，
所以“第 0 行”是最上面一行，“第 1 列”是第二列，从上往下读。把鼠标指向 C 的某一格（手机上点一下）就能看到。

## 2. 形状规则

形状规则就来自那一条规则。要把 A 的一行和 B 的一列逐个数相乘，
这一行和这一列的长度必须相同。在 NumPy 里，以及在整个课程里，`@` 都表示矩阵乘法。所以：

$$
(n, k) \; @ \; (k, m) \;\to\; (n, m)
$$

内侧的两个数必须相等，并且会消失。剩下的是外侧的两个数。内侧的数相等时，我们说这两个形状**对得上**。

<Predict id="same-shape" />

答案里的那次翻转有个名字：**转置**（transpose），写作 `B.T`。`B` 的第 i 行变成 `B.T` 的第 i 列，
所以 (3, 2) 的矩阵变成 (2, 3)。你会在第 6 关用到它，在注意力里还会再用到。

<Stuck q="为什么不直接逐格相乘，就像两个矩阵相加那样？">

这种运算也有。在 NumPy 里它是 `A * B`。它要求两个矩阵形状相同，
在掩码之类的地方会用到。但它从不在不同位置之间混合信息：
(0,0) 这一格永远只看到 (0,0) 这一格。

矩阵乘法会混合。每个输出格都把一整行和一整列结合起来。
神经网络的一层需要的正是这种混合。每个输出都是所有输入的加权和。

</Stuck>

## 4. 你会见到上百次的形状

真实的模型不会一次只乘一个句子。它把几个句子叠成一个**批**（batch），所以输入
有三个维度：(batch, length, features)。乘一个权重矩阵只会动到最后一个维度。
规则不变：内侧的数必须相等，并且会消失。

<Deeper title="为什么一层是 (batch, length, `d_in`) @ (`d_in`, `d_out`)">

把左边的矩阵看成“每个词一行”。每个词是一个有 `d_in` 个数的列表。
把右边的矩阵看成“每个新特征一列”。每一列说明每个输入数有多少
进入这个新特征。

所以 `X @ W` 把每个词的 `d_in` 个数变成 `d_out` 个新数，而且每个词用的是同一个 `W`。
`W` 里没有任何关于批大小或句子长度的东西。这就是为什么同一层
既能处理 2 个句子的批，也能处理 2000 个的；既能处理 5 个词的句子，也能处理 500 个词的。

在第 14 关你会看到 `X @ W_Q`、`X @ W_K`、`X @ W_V`：三个这样的乘法，一个接一个。

</Deeper>

## 5. 广播：把形状不同的数组相加

两个形状相同的矩阵相加很简单：逐格相加。但模型经常要加上*更小*的东西：
给每个样本加同一行偏置，给每个词加同一行掩码。NumPy 为此有一条规则，叫
**广播**（broadcasting）：大小为 1 的维度会被拉伸（复制），直到和另一个数组对上。

一列 (4, 1) 加一行 (1, 5)：这一列被横向复制 5 次，这一行被纵向复制 4 次，
然后逐格相加。

规则是**从右往左**一次检查一个维度：

1. 两个大小相等，没问题。
2. 其中一个是 1，把它拉伸成另一个。
3. 否则，报错。

<Stuck q="NumPy 真的把这一列复制了 5 次吗？这不浪费吗？">

并没有复制。NumPy 只记住这个维度的大小是 1。每次读取拉伸后数组的某一格时，
它读的都是存着的同一个数。这就是实验台里那些格子是浅色的原因：它们不是真正的格子。
所以把一行 (1, 5) 和一百万行做广播，这一行不会多占任何内存。

</Stuck>

<Deeper title="X @ W + b 里的偏置也是一次广播">

一层计算的是 `X @ W + b`。`X @ W` 是 (N, `d_out`)：每个样本一行。`b` 是 (`d_out`,)，每个
输出一个数。按照规则，`b` 被当作 (1, `d_out`)，向下拉伸成 N 行，所以每个样本加的都是
同一个偏置。没人去写这个复制；广播替你做了。从第 5 关开始，你在每一层都会用到它。

</Deeper>

## 7. 沿一个轴求和

很多步骤都要沿表格的某一个方向把数加起来。在 NumPy 里用 `axis` 选方向。
取形状为 (3, 2) 的 A：

```
A = [[1, 2],
     [3, 4],
     [5, 6]]
A.sum(axis=0)  →  [9, 12]       # 沿行往下加：每列一个总和，形状 (2,)
A.sum(axis=1)  →  [3, 7, 11]    # 沿一行横着加：每行一个总和，形状 (3,)
A.mean(axis=0) →  [3, 4]        # 同上，再除以 3 行
```

`axis=0` 去掉行。`axis=1` 去掉列。你指定的那个轴就是消失的那个。

现在把两个想法放到一起。`X.mean(axis=0)` 的形状是 (d,)：每列一个均值。从 `X`
（形状 (N, d)）里减去它就是一次广播：这一行均值被向下拉伸到全部 N 行。结果的每一列
都以 0 为中心。第 16 关的 LayerNorm 也用同样的方式居中，只不过是对每一行而不是每一列：它沿
最后一个轴取均值，每个词一个均值，再减去它。
