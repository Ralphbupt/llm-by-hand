# Deploying to Cloudflare Pages

The site is fully static: `npm run build` in `site/` writes everything to `site/dist`.
Python runs in the browser with Pyodide, loaded from the official CDN (cdn.jsdelivr.net), so no large files ship.

## 1. Create the project

Cloudflare dashboard → Workers & Pages → Create → Pages → connect the Git repository (or upload `dist` with
`npx wrangler pages deploy dist` after `npm run build`).

| Setting | Value |
| --- | --- |
| Framework preset | Astro |
| Root directory | `site` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node version | 22 (from `site/.node-version`; or set `NODE_VERSION=22`) |
| Environment variable | `PUBLIC_GA4_ID` = your GA4 measurement ID (`G-…`), Production only |

Without `PUBLIC_GA4_ID` the site has no analytics code and no consent bar (keep it unset for preview deployments).
The public URL lives in one place: `src/config/site.ts` (`SITE_URL`). Change it there if the domain changes.

## 2. Custom domain `llm.liko.page`

Pages project → Custom domains → Set up a custom domain → `llm.liko.page`.
If `liko.page` is a zone on the same Cloudflare account, Cloudflare adds the record itself:
`CNAME llm → <project>.pages.dev` (proxied). Otherwise add that CNAME at your DNS provider, then wait for the
certificate (a few minutes). Add the domain in the dashboard first; a bare CNAME alone is not enough.

## 3. Analytics (GA4)

1. Google Analytics → Admin → Create property "LLM by Hand" → Web stream for `https://llm.liko.page`.
2. Copy the measurement ID (`G-…`) into the Pages environment variable `PUBLIC_GA4_ID` and redeploy.
3. In the web stream, keep Enhanced measurement on (page views, scrolls, outbound clicks).
4. Optional: Admin → Custom definitions → add event parameters `level`, `page_slug`, `exercise_id`, `rung`,
   `result`, `branch` so the course events can be broken down in reports.

Events: `level_start`, `checkpoint_pass`, `level_clear`, `boss_pass`, `test_out_pass`, `hint_open`, `answer_reveal`,
`code_run`, `side_trip_open`, `glossary_open`, `download`. They are sent only after the visitor presses Allow
(Consent Mode v2, ads storage always denied), and never carry answers, code or typed text.

## 4. Check after the first deploy

```bash
curl -sI https://llm.liko.page/ | grep -i -E "^(HTTP|cache-control|x-content-type)"
curl -s  https://llm.liko.page/robots.txt
curl -s  https://llm.liko.page/sitemap.xml | head
curl -s  https://llm.liko.page/llms.txt | head
curl -sI https://llm.liko.page/learn/attention.md | grep -i content-type   # text/markdown; charset=utf-8
```

- Pick any `/_astro/…` file from a page's source and check `curl -sI` shows `immutable`.
- Open a level and view the source: one `<title>`, a description, `rel="canonical"`, `og:image` (open the image URL),
  JSON-LD. Test one level in Google's Rich Results Test.
- Google Search Console → Add property (Domain `liko.page`, or URL prefix `https://llm.liko.page/`) → verify with
  the DNS TXT record → Sitemaps → submit `https://llm.liko.page/sitemap.xml`.
- With `PUBLIC_GA4_ID` set: open the site in a private window, press Allow, and check GA4 → Reports → Realtime.
  Press "No thanks" in another window: no request to googletagmanager.com should appear.

## Crawlers

`robots.txt` (generated by `src/pages/robots.txt.ts`) allows everything, including AI crawlers
(GPTBot, ClaudeBot, PerplexityBot, Google-Extended, …), because the course is meant to be found.
To keep AI crawlers out, change their groups there to `Disallow: /`.
